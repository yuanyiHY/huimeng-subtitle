# 首次启动欢迎向导 - 设计方案

## 功能目标
让小白第一次打开 Korean Studio 时，能清楚地知道：
1. 这个软件能做什么
2. 哪些功能免费、哪些需要配置
3. 怎么开始使用

---

## 触发条件
```javascript
// 首次启动检测逻辑
const isFirstLaunch = !localStorage.getItem('ks_welcomed')
const hasAnyApiKey = (await fetch('/api/config')).data.mt_api_key || 
                     (await fetch('/api/config')).data.main_api_key

if (isFirstLaunch || !hasAnyApiKey) {
  showWelcomeModal()
}
```

## 前端实现要点

### HTML 结构
```html
<!-- 欢迎向导弹窗 -->
<div id="welcomeModal" class="modal" style="display:none">
  <div class="modal-content welcome-wizard">
    <!-- 步骤 1 -->
    <div class="wizard-step active" data-step="1">...</div>
    <!-- 步骤 2 -->
    <div class="wizard-step" data-step="2">...</div>
    <!-- 步骤 3 -->
    <div class="wizard-step" data-step="3">...</div>
  </div>
</div>
```

### JavaScript 逻辑
```javascript
// 启动时检测
async function checkFirstLaunch() {
  const welcomed = localStorage.getItem('ks_welcomed')
  if (!welcomed) {
    await showWelcomeWizard()
    localStorage.setItem('ks_welcomed', Date.now())
  }
}

// 显示向导
function showWelcomeWizard() {
  return new Promise(resolve => {
    const modal = document.getElementById('welcomeModal')
    modal.style.display = 'flex'
    
    // 处理步骤切换
    modal.addEventListener('click', e => {
      if (e.target.matches('[data-next]')) {
        goToStep(currentStep + 1)
      } else if (e.target.matches('[data-skip]')) {
        modal.style.display = 'none'
        resolve('skipped')
      } else if (e.target.matches('[data-goto-settings]')) {
        modal.style.display = 'none'
        switchPage('settings')
        resolve('configured')
      }
    })
  })
}
```
